# Vande Wellness — Feature Map

Comparable wellness-app capabilities mapped to Vande Wellness features. This describes **capability parity**, not copying any third-party product.

| Wellness app concept | Vande Wellness feature |
|---------------------|------------------------|
| Specialist consultations | Virtual/in-person Ayurvedic consultations, practitioner booking, follow-ups |
| Personalized care plan | Ayurvedic wellness plan with supplements, yoga, nutrition, lifestyle, detox |
| Supplements & products | Practitioner-recommended products via VandeCart deep links |
| Yoga, nutrition, lifestyle | Care plan items: yoga therapy, diet guidance, dinacharya, stress tools |
| Live events & community | Webinars, meditation circles, retreats, courses (Learn tab) |
| Progress tracking | Mood check-ins, adherence, metric trend cards |
| Care-team messaging | Secure chat UI with categories and generic push previews |
| Membership & ongoing care | Membership plans with entitlements, Stripe upgrade flow |
| Intake & onboarding | Multi-step wellness questionnaire with non-diagnostic scores |
| Family plans | Family profile display, spouse/family membership tiers |

## Vande-specific differentiators

- Ayurvedic branding and copy ("Namaste", "Today's balance", dosha-oriented intake)
- Panchakarma and home detox program support in care plans
- VandeCart integration for herbal products and detox kits
- BAMS/MD Ayurveda practitioner credentials
- Global telehealth membership tiers
